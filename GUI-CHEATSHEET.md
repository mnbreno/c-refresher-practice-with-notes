# C Calculator GUI Cheat Sheet

| Button | Action |
| --- | --- |
| `0` to `9` | Enter a digit |
| `.` | Start or continue a decimal number |
| `+`, `-`, `*`, `/` | Choose an operation |
| `=` | Calculate |
| `+/-` | Toggle the displayed number's sign |
| `DEL` | Delete the last displayed character |
| `C` | Clear the current calculation |

This Win32 version is mouse-operated. Keyboard event bindings are not implemented in the C GUI.
